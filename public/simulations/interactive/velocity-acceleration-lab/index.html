🚀 Velocity vs Acceleration Lab

Fly the ship. The yellow arrow is velocity — where you're actually going. The orange arrow is acceleration — how your velocity is changing.

What to watch for

  • Coasting: don't touch anything — the ship keeps the same velocity forever (Newton's 1st law). Yellow arrow frozen.
  • a ∥ v: thrust while pointing the same way you're moving — the yellow arrow grows, path stays straight.
  • a ∥ −v: pick "Slow Down" — the orange arrow fights the yellow one until speed hits zero, then wins and pushes backward.
  • a ⊥ v: pick "Curve" — the orange arrow stays sideways to the yellow one, so the path bends like a ball thrown sideways.
  • Locked Burn + Steer: engine stays on — rotate with ←→ and watch constant acceleration carve curves.

Keys: ←→ rotate   ↑ thrust   P pause   R reset

Physics rule of thumb: acceleration is the rate of change of velocity. Point them the same way → speed up. Opposite → slow down. Sideways → turn. None → coast forever.
