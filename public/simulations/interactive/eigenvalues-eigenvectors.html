After you calculate
This tool will show eigenvalues, eigenvectors, the transform matrix 𝒯, and the diagonal matrix 𝒟 when the matrix can be diagonalized.

For 2×2: solve det(A − λI) = 0, then solve (A − λI)v = 0 for each eigenvalue. If there are enough independent real eigenvectors, the tool also forms 𝒯 and 𝒟.
