C00lnerd Tutoring Website - Offline Usage Instructions
=====================================================

IMPORTANT: This website needs to run on a local web server to work properly.
Simply opening the HTML files directly will cause navigation issues.

EASY METHOD (Recommended):
=========================
1. Double-click "start_website.bat"
2. Wait for the server to start
3. Open your web browser
4. Go to: http://localhost:8000
5. Enjoy the complete website with working navigation!

MANUAL METHOD (Advanced):
========================
1. Open Command Prompt or Terminal
2. Navigate to the "dist" folder
3. Run: python -m http.server 8000
4. Open browser to: http://localhost:8000

WHAT WORKS:
===========
✅ All navigation links
✅ Programming lessons with copy buttons
✅ Interactive fractal tree simulator
✅ Physics simulations
✅ Practice tools and calculators
✅ Complete offline functionality

TROUBLESHOOTING:
===============
- If Python is not installed, download from python.org
- If port 8000 is busy, try: python -m http.server 8080
- Make sure to use http://localhost:8000 (not file:// paths)

WHAT'S INCLUDED:
===============
- 12 Complete Python Lessons (Mystery Numbers to Fractals)
- Interactive Simulations (Fractal Tree, N-Body Physics, etc.)
- Practice Tools (Projectile Motion Calculator, etc.)
- All educational resources work completely offline
